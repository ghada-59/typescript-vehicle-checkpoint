# TypeScript Vehicle Checkpoint

## Run the project

1. Install dependencies:
   ```bash
   npm install
   ```
2. Compile TypeScript into JavaScript:
   ```bash
   npm run build
   ```
3. Run the compiled JavaScript:
   ```bash
   npm start
   ```

Expected console output:

```text
Car engine started
```

The source code is in `index.ts`. The TypeScript compiler generates `dist/index.js`.
